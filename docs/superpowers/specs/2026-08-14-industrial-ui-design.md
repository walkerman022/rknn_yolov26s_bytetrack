# 电子围栏系统工业界面 (DetectUI2) 设计规格

日期: 2026-08-14
状态: 已确认(用户评审后定稿)
参考文档: `ui/电子围栏系统界面设计.md`(参考图描述)

## 1. 背景与目标

现有软件 `detect_ui`(C++ Qt 移植版, `src/detect_ui.cpp`)功能完整但为"配置表单"风格, 不符合工业现场操作界面的定位。本规格设计一套**暗黑工业风**界面, 布局/配色严格按参考图, 功能上保留现有全部能力, 作为**独立新程序** `DetectUI2` 交付。

## 2. 架构决策

- **独立程序**: 新增 `src/industrial_ui.{h,cpp}` + CMake 新目标 `DetectUI2`。现有 `detect_ui` 与 `Detect` 核心**完全不动**、可并行构建。
- **复用现有数据协议**: `DetectUI2` 通过 QProcess 启动现有 `Detect` 二进制, 解析其 stdout 日志; 视频画面通过 `--no-display --gui-frame` 机制轮询 `frame.jpg` 显示(沿用现有帧率/大小双条件判新的竞态修复方案)。
- **事件协议小改**: 对 `main_MultiDetect.cpp` 增加 ~3 行 `push_event` 输出(可回退), 见 §5。
- **技术栈**: Qt5 Widgets (与现有 DetectUI 相同, 板上 `qtbase5-dev`), 单文件 UI 程序, 不引入新依赖。

## 3. 视觉规范 (严格按参考图)

| 元素 | 值 |
|---|---|
| 主背景色 | 炭灰 `#2B2B2B` ~ `#333333` |
| 状态绿 | `#00B027` / `#00FF00` (OK 卡、通过状态) |
| 警示橙黄 | `#FF9900` / `#FFFF00` (Logo 高亮、PLC 异常标签) |
| 警示红 | NG 卡状态色 (约 `#D32F2F`, 按 OK 绿同视觉权重设计) |
| 渲染区背景 | 黑灰棋盘格 (Checkerboard, 经典画板) |
| 风格 | 扁平卡片 + 模块分隔, 无圆角渐变, 高对比度, 模块可停靠观感 |

字体: 默认系统字体, 数据表/日志用等宽字体(DejaVu Sans Mono)。

## 4. 布局 (T 字型 + 侧边栅格)

```
+-------------------------------------------------------------------------+
| 顶部工具栏: Logo(JEE 橙色) 名称 | 图标按钮组 | 窗口控制(最小/最大/关闭)     |
+------------------------------------+------------------------------------+
|                                    |                                    |
|          渲染结果区                 |            OK/NG 状态卡             |
|      (棋盘格主视口, 显示画面+围栏)   |       (大面积, 绿=OK / 红=NG)       |
|                                    |                                    |
+------------------------------------+                                    |
| 视频信息: 处理/实时FPS 分辨率 帧号   |        数据表 (事件记录)             |
+------------------------------------+------------------------------------+
| 状态栏: 当前用户 | 方案名称 | PLC连接 | 相机连接 | 剩余存储 | 精确时间       |
+-------------------------------------------------------------------------+
```

### 4.1 顶部工具栏

- 左侧: 橙色 Logo 块 + 名称 "JEE 安徽巨一科技股份有限公司"
- 中间: 9 个 `QToolButton`(图标在上、文字在下, 单色线条图标风格), 按参考图顺序:
  打开项目、系统参数、相机设备、外部通信、数据查询、画布设置、用户管理、开始、停止
- 右侧: 最小化 / 最大化 / 关闭 (通过窗口 flags 实现)

### 4.2 渲染结果区

- `QLabel` 承载画面, 背景为棋盘格 QSS(深灰黑相间)
- 显示 `frame.jpg`(缩放至视口, 保持宽高比, 平滑缩放)
- 检测到围栏(`zone.txt` 有效)时在画面上叠加半透明围栏多边形(默认橙色描边)

### 4.3 OK/NG 状态卡

- 大面积卡片(参考图右侧约半屏), 中央巨大文字
- 状态判定: **围栏内人数 (`zone_now`) == 0 → 绿底黑字 OK; ≥1 → 红底白字 NG**
- 状态由事件/日志驱动持续更新; 未启动检测时显示中性灰底 "----" 或空态
- 仅变色/变字, 无声音、无动画(用户已确认)

### 4.4 数据表 (事件记录)

- `QTableWidget`, 表头: 序号、时间、事件、位置
- 事件类型与显示: **进入**(人物首次出现, 中性色)、**警报**(人物进入围栏, 红色高亮)、**离开**(人物离开围栏, 绿色)
- 位置列: 显示围栏名称(系统参数中配置, 默认 "电子围栏")
- 行序: 新事件插在顶部; 表格滚动时状态持续更新; 无事件时显示空态提示

### 4.5 视频信息栏

- 处理FPS、实时FPS(来自 `[Frame ...]` 日志)、分辨率、帧号

### 4.6 状态栏

| 项 | 数据来源 |
|---|---|
| 当前用户 | 系统登录名 (QDir::home 推断) |
| 方案名称 | 系统参数中配置, 默认 "电子围栏" |
| PLC连接 | 系统参数中配置(默认"错误", 黄色警示块样式), 可下拉选 正确/错误 |
| 相机连接 | Detect 启动且视频信息收到 → 绿; 否则灰/红 |
| 剩余存储 | `QStorageInfo` 当前工作盘剩余空间 |
| 精确时间 | `QTimer` 每秒刷新本地时间 |

## 5. 事件协议 (Detect 侧小改)

现有 `push_event` 已输出(UI 直接解析):
- `[Zone] Person id=%d ENTERED (total in: %d)` → **警报**
- `[Zone] Person id=%d EXITED (total out: %d)` → **离开**

新增(在 `main_MultiDetect.cpp` track 首次出现处, ~3 行, 可回退):
- `[ENTER] track=%d` → **进入**(该 track 首次出现在视频中, 一个 id 只记录一次进入)

UI 侧: 每个 track id 记录一次进入事件; `[Zone] ENTERED/EXITED` 与 track 对应, 生成警报/离开事件。围栏内人数由现有 `zone_now` 计数驱动(不自行推算)。

## 6. 对话框 (配置收敛)

| 按钮 | 对话框内容 |
|---|---|
| 打开项目 | 选择视频文件(等效现有"视频文件+浏览") |
| 系统参数 | 现有全部配置项: 视频/模型/阈值/日志/画面/误检目录/围栏判定(混合/脚点/面积)/抽帧间隔/误检判断帧/漏检判断帧/围栏判断帧/围栏防抖 + 新增**围栏名称**、方案名称、PLC状态 |
| 相机设备 | 运行方式选择(本软件启动/监视文件) + 使用sudo |
| 外部通信 | 暂以 PLC 参数承载, 功能语义不明确的不强行造功能 |
| 数据查询 | 两个 tab: 误检帧画廊(缩略图横条, 点击放大对话框) + 控制台输出(实时滚动日志) |
| 画布设置 | 围栏名称/画布背景色等画布相关参数 |
| 用户管理 | 参考图占位按钮, 无实际功能(当前单用户系统) |
| 开始 / 停止 | 工具栏主操作: 启动检测(QProcess 启动 Detect)/ 停止(信号组终止, 3s 强杀) |

设置持久化: 沿用 `detectui.ini` 模式, 独立 ini 文件(如 `detectui2.ini`), 保存/恢复全部参数。

## 7. 运行逻辑 (移植自现有 detect_ui, 保持不变)

- 启动: 检查 `zone.txt` → 不存在则先启动画围栏模式(`--draw-zone-only`), 画完自动开始; 存在则直接启动
- 画围栏: `--draw-zone-only` 子进程, 完成后自动衔接
- 停止: `kill(-pgid, SIGTERM)`, 3s 未退强杀; sudo 边界处理沿用(非 root 界面不勾 sudo)
- 监视文件模式: 增量读日志文件(等效现有)
- 误检帧目录准备/清空、缩略图刷新: 沿用现有逻辑, 迁入"数据查询"对话框
- 日志正则解析: 全部复用现有正则(`[Frame]`/`[INFO]`/`[FALSE-POS]`/`[MISS]`/`[STATS]`/Video + 新增 `[ENTER]`)

## 8. 测试策略

1. **编译验证**: 本机(Windows + 交叉工具链)/板上 Qt5 环境, `DetectUI2` 目标编译通过; 现有 `DetectUI` 不受影响
2. **运行验证**(板上或本机仿真): 用现有调试视频跑通, 确认:
   - 事件表依次出现 进入→警报→离开
   - OK 卡在围栏有人时翻转为 NG(红), 无人恢复 OK(绿)
   - FPS/分辨率/帧号实时刷新; 状态栏时间走动、相机连接变绿
   - 误检帧画廊与旧版行为一致
3. **回归**: 现有 `DetectUI` 构建与行为不受影响(不修改其源码/目标)

## 9. 范围外 (YAGNI)

- 声音/动画报警(用户确认仅变色)
- 多围栏同时检测(当前系统单围栏 `zone.txt`)
- 用户权限管理、远程通信(无数据源, 仅占位)
- 移动端/浏览器端界面
