# 电子围栏系统界面设计

这张图片展示的是一款典型的**工业机器视觉/自动光学检测（AOI）系统软件界面**。以下从风格设计、颜色搭配、布局排版及模块构成四个维度为您进行详细描述：

## 1. 风格设计 (Design Style)

- **暗黑工业风 (Dark Industrial UI):** 采用了工厂工控机非常常见的深色/暗黑主题风格。这种设计能够极大程度地减少车间操作人员长时间盯着屏幕产生的视觉疲劳。
- **高对比度与功能导向:** 界面放弃了复杂的装饰与圆角渐变，采用直观的扁平卡片与模块分隔，通过极高的色彩对比度（如大块鲜亮绿色与深暗背景）来确保操作员在远距离或复杂光照环境下也能一眼识别人工/检测状态。
- **模块化可停靠 (Dockable):** 各大区域带有标题栏与小图标（如固定、小窗、关闭按钮），说明其采用了模块化分屏/可拖拽（Dock Widget）设计。

## 2. 颜色搭配 (Color Palette)

- **主背景色（深灰/近黑）：**`#2B2B2B` ~ `#333333` 左右的炭灰色，奠定了沉稳、专业的工业软件基调。
- **状态指示色（高亮绿 & 警告黄）：**
  - **亮绿色 (#00B027 / #00FF00)：** 用于右侧占据巨大面积的“OK”检测结果状态块，具有极强的视觉冲击力。
  - **橙黄色 (#FF9900 / #FFFF00)：** 用于顶部企业 Logo (JEE)、图标高亮以及底部状态栏中的“PLC连接: 错误”黄色警示标签。
- **渲染区（灰黑棋盘格）：** 左侧视口采用了经典的黑灰相间棋盘格（Checkerboard）画板背景，用于表示无图像加载或透明无渲染状态。

## 3. 界面布局与排版 (Layout & Topology)
整个界面采用标准的 **“T字型 + 侧边栅格”** 工业软件经典布局，结构层次分明：

```
+-------------------------------------------------------------------------+
|                              顶部工具栏                                  |
+------------------------------------+------------------------------------+
|                                    |                                    |
|             渲染结果区              |             数据展示区              |
|            (棋盘格主视口)           |          (巨大 OK + 数据表)         |
|                                    |                                    |
+------------------------------------+                                    |
| 视频信息： 处理/实时FPS：            |                                    |
+------------------------------------+------------------------------------+
|                              底部状态栏                                  |
+-------------------------------------------------------------------------+

```

## 4. 详细区域结构说明

### 顶部导航与工具栏 (Top Toolbar)

- **左侧：** 橙色的企业品牌 Logo 与名称（`JEE 安徽巨一科技股份有限公司`）。
- **中间：** 一排纵向排列（图标在上、文字在下）的功能按钮，包括：*打开项目、系统参数、相机设备、外部通信、数据查询、画布设置、用户管理、开始、停止*。图标均为单色线条风格。
- **右侧：** 传统的窗口控制按钮（最小化、最大化、关闭）。

### 左侧核心区 (Main Viewport & Logs)

- **上半部（渲染结果）：** 占据左侧大部分区域，作为摄像头采集图像或算法处理结果的展示窗口。
- **下半部（视频信息）：** 紧贴渲染区下方，内容包括视频信息，处理/实时FPS，方便实时监控系统运行日志

### 右侧数据展示区 (Data Panel)

- **顶部 OK 牌：** 占据右侧约一半空间的大面积亮绿卡片，中间印有巨大的黑色“OK”字样，直观反馈当次检测结果。
- **中部数据信息：** 采用双列文本布局，展示关键参数。
- **底部数据表格：** 白底黑字的结构化表格，包含 *序号、时间、事件、位置* 等列表头。事件包括进入，警报，离开。位置就是根据所画围栏的名称来。

### 底部状态栏 (Bottom Status Bar)

- 放置低频但关键的信息：左侧显示*当前用户*与*方案名称*；中间与右侧嵌入了设备连接状态（如带黄色高亮块的 *PLC连接*、*相机连接*）、*剩余存储空间* 以及 *系统当前精确时间*。
